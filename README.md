# Мой день

Первая рабочая версия личного веб-приложения на Next.js.

## Уже есть

- отдельные страницы: Главная, Дела, Расходы, Настройки;
- добавление и выполнение задач;
- отметка важных задач;
- запись расходов;
- стандартные и пользовательские категории;
- календарь на главной с возможностью свернуть;
- отметки дней, в которых есть задачи или расходы;
- адаптивный интерфейс для телефона;
- нижняя мобильная навигация;
- плавные анимации Motion;
- хранение данных в localStorage.

## Запуск

Нужен Node.js 20.9+.

```bash
npm install
npm run dev
```

После запуска откройте http://localhost:3000
