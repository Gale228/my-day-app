# Мой день v1.6 — «Моё / Общее»

В этой версии добавлено совместное пространство для пары/семьи.

## Возможности

- отдельный режим «Моё / Общее»;
- создание общего пространства;
- присоединение второго пользователя по 8-символьному коду;
- общие задачи;
- общий список покупок;
- совместные расходы;
- месячный общий бюджет;
- отдельные категории общих расходов;
- RLS: доступ к общим данным только у участников пространства;
- личные задачи, расходы, цели, привычки и заметки остаются личными.

## Supabase

Перед первым запуском v1.6 выполни файл:

`supabase/v1.6-shared-space.sql`

через Supabase → SQL Editor.

## Сценарий подключения пары

1. Первый пользователь открывает `/shared` и создаёт пространство.
2. Приложение показывает код приглашения.
3. Второй пользователь входит в свой аккаунт, открывает `/shared` и вводит этот код.
4. После подключения общие задачи, покупки и расходы видны обоим аккаунтам.
