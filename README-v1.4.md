# Мой день v1.4

Новые разделы: цели, привычки, заметки, аналитика расходов, тёмная тема и PWA.

## Перед запуском
1. Выполнить SQL из `supabase/v1.4-life-features.sql` в Supabase SQL Editor.
2. `npm install`
3. `npm run dev`

## PWA
На localhost service worker работает. Для реальной установки на телефон после публикации нужен HTTPS.

## Git после обновления
```bash
git status
git add .
git commit -m "Add goals habits notes analytics dark theme and PWA"
git push
```
